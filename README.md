# RUNMATE SEOUL · 런메이트 서울

서울 2030을 위한 소셜 러닝 매칭 플랫폼 (과제용 프로토타입)

## 주요 기능
- **서울 한정**: 서울 25개 자치구만 선택 가능, 서울 밖 지명 입력 차단, 코스·동네 인증 모두 서울 안에서만
- **실제 지도 코스 갤러리**: Esri 위성사진(World Imagery, API 키 불필요) 위에 실제 위경도 좌표로 그린 코스 카드 (스트라바 인증샷 스타일)
  - 한강·공원·하천·업힐 14곳 + GPS 아트 3곳(경복궁 댕댕이런, 여의도 고구마런, 연남 하트런)
  - 카드의 `지도 ↗` → 확대/이동 가능한 인터랙티브 지도 (Leaflet)
  - `실제 도로에 맞춰 보기` → OSRM 길찾기로 실제 보행로를 따라가는 경로 표시
- **나만의 코스 등록**: 지도에 클릭해서 그리기 / 스트라바·가민 GPX 업로드 / 도로에 맞추기, 서울 밖 지점은 등록 불가
- **지정 코스 크루 / 자유 코스 크루**: 자유 코스는 멤버가 각자 코스를 골라 달리고 인증, 특정 구 크루는 그 구 동네 인증 러너만 참여
- **가입 인증 (당근마켓 동네 인증 방식)**
  1. 휴대폰 본인인증 (이름·생년월일·번호, 만 19~39세만 가입) — *데모: 인증번호는 화면 알림으로 표시*
  2. 서울 동네 인증 — 브라우저 GPS 위치 → OpenStreetMap 역지오코딩으로 서울 ○○구 판정 (30일 유지)
  3. 러너 프로필
  - 인증한 러너만 참가 신청·크루 개설·코스 등록 가능
- **런허브(RUN HUB) 러닝 렌탈 — DECATHLON × CU 협업 콘셉트**: 러닝 코스 근처 CU 편의점 13곳(가상 지점)을 오프라인 대여 거점으로 운영
  - 데카트론 KIPRUN 실제 모델(사진·정가 포함): 킵코어·킵라이드 맥스·킵스톰 챌린저·킵서밋 러닝화, 반팔티·쇼츠·바지·윈드 자켓·패딩 베스트, 트레일 베스트·암밴드·플래시 라이트, 양말(판매) + CU 짐 보관함
  - 반납 시 데카트론 구매 할인 쿠폰 (콘셉트)
  - 예약: 지점·날짜·픽업 시간·품목·사이즈 선택 → 결제(데모) → 픽업 코드(QR) 발급, 3시간 안에 서울 모든 런허브에 반납
  - 런 스타터 세트(러닝화+상의+하의) 1,000원 할인, 지점별 사이즈 재고 표시
  - 크루·코스 상세에 "근처 런허브(도보 n분)" + 크루 시작 30분 전 픽업으로 자동 맞춘 예약 버튼
  - 본인인증 회원만 대여 가능, 예약 내역은 ‘내 러닝’에서 확인·취소
- **매칭 테스트**: 페이스·거리·코스 취향·시간대·성향 5문항 → 매칭률 TOP 3
- 데이터는 브라우저 localStorage에 저장 (서버 없음)

## 참고 / 한계
- 기본 코스 17개는 OpenStreetMap 산책로·도로 데이터와 OSRM 보행 경로로 만들고, 위성사진과 겹쳐서 확인한 좌표예요. 더 정확하게 하려면 직접 달린 GPX를 `나만의 코스 등록`으로 올리세요.
- 실제 본인인증은 PASS·통신사 본인인증 API(포트원 등) 연동과 사업자 계약이 필요해서 데모로 구현했어요.
- 위치 기능은 https 주소(예: Vercel 배포)에서 가장 잘 동작해요. PC 발표용으로 `데모 위치(서울시청)로 인증` 버튼을 넣어뒀어요.
